## 2.8.24 修的三件事（294 反馈）

1. **不播放歌曲时充电岛没有背景素材**
   选主逻辑原来是 `bestRoot = newestRoot ?: …`，新冒出来的岛无条件抢走视频宿主，
   没有音乐岛兜底。现在分级：最新岛必须"可见且有面积"→ 上轮粘滞 → 音乐岛 → 面积最大；
   换宿主时强制重新起播（原来只在素材路径变化时重载，首帧没加载就一直黑）。
2. **小岛 / 展开岛四周一条黑边**
   视频层外扩从固定 2pt 改成按宿主高比例（`diVideoBleed`，2.5~10pt），
   并把胶囊中间层（容器/内容视图）的圆角对齐到宿主圆角，取消直角裁切。
   日志关键字：`素材铺满`。
3. **展开素材循环时闪一下**
   换成双播放器无缝接力（`seamlessTick`）：离片尾 0.10~0.40s 起备用播放器，
   上屏切换不重建 item。日志关键字：`循环模式` / `无缝循环接缝`。

## 功耗红线（改代码前先读）

- 帧目录签名 ≤ 1s 算一次；树遍历都带 0.15~0.25s 缓存；
- 素材链接静止 60→30fps；遮罩探针稳定态 8fps；
- 生产版关闭层树 dump。

## 当前功能状态（别乱动）

- 专辑遮罩只作用于「正在播放的音乐小岛」的左侧专辑位，判定靠结构特征
  （左 26x22 门户 + 右 22x22 音频门户成对 + 在播校验 `diIsNowPlayingHost`）。
- 展开岛 / 充电岛 / 通知岛 / 来电岛一律不套遮罩、不旋转。
- 挂载宿主拆两个：`matRoot`(音乐岛，管遮罩玻璃/帧率素材/门户隐藏)、
  `bestRoot`(视频宿主，管小岛背景视频)。
- 藏门户层必须登记 `diMarkLayerHiddenByUs`，否则音乐岛判定连锁失败 → 整岛空白。
- 设置页：锁屏通知页 / 专辑遮罩页 footer 已删空，组标题「开启灵动岛定制」，不要自行加回说明文字。
